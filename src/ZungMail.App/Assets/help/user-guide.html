Start here

01 · 快速开始

#

第一次打开 ZungMail 时，先完成三件事：添加邮箱账户、确认同步成功、设置一份签名。之后就可以在「统一收件箱」里处理邮件了。

打开设置 → 账户

点主界面右上角的齿轮按钮，左侧选「账户」，再点「添加账户」。

填写邮箱地址与授权码

QQ、163、企业邮箱通常使用「授权码」而不是网页登录密码。QQ 邮箱可在网页版「设置 → 账户 → POP3/IMAP/SMTP 服务」中开启 IMAP 并生成授权码。

测试连接并保存

客户端会自动匹配常用服务商的 IMAP / SMTP 地址与端口。测试通过后保存账户，回到主界面等待首次增量同步。

从「统一收件箱」开始

首次同步会先拉取邮件头，正文按设置里的「默认收取策略」按需下载；历史邮件很多时，列表会分页显示。

可选：设置签名

设置 → 签名，为每个账户准备一份富文本签名；写信切换发件账户时会自动替换。

账户右键菜单与收取策略

  • 在左侧账户名上点右键：收取（只收这个账户）、新建文件夹（建在该账户根目录）、 整理文件夹（打开历史邮件清理，范围默认限定这个账户）、导入邮件（把 Foxmail / Outlook 导出的 .eml 导入）、 设置（直接打开这个账户的配置）。同步进行中或账户配置不完整时，「收取」会自动变灰。
  • 在任意文件夹上点右键还可以「整理此文件夹」，清理窗口顶部会显示当前作用域，点旁边的「清除」恢复全账户范围。
  • 收取设置（设置 → 账户 → 编辑）：每个账户可单独选「完整收取（正文 + 附件）」「仅收取正文（附件按需下载）」「仅收取邮件头」，默认「继承默认策略」跟随设置 → 通用里的全局档位。
  • 「仅收取正文」时附件不会自动下载：附件仍会列出来，右键选择「下载附件」即可（正文里内嵌的图片照常显示）。
首次同步较慢是正常的。

同步进度在状态栏右侧；可以继续浏览已缓存的邮件。不要重复点刷新，客户端会复用正在进行的同步。

数据在本机。

邮件、索引、标签、规则与草稿都保存在本机数据目录（默认 %APPDATA%\ZungMail）；账户口令使用 Windows DPAPI（按当前用户派生密钥）加密，不上传第三方服务器。从旧版 MailClient 升级过来的用户不用手工搬数据：第一次启动会自动接管旧目录，详见第 10 章「从旧版 MailClient 升级：数据自动接管」。

Account & sync

02 · 账户与同步

#

账户页负责登录信息、服务器参数、标识色与启停状态。多个账户会同时出现在左侧文件夹树与「统一收件箱」中。

添加与编辑账户

  • 账户页右上或列表下方点「添加账户」；已有账户点「编辑」修改名称、邮箱、授权码、服务器与端口。
  • 标识色只影响界面显示，用于快速区分账户；点击色块可从色盘选色，也可以直接选常用色。
  • 保存前建议先「测试连接」，确认 IMAP 与 SMTP 都可达。若服务商要求 SSL，端口通常为 IMAP 993、SMTP 465。
  • 停用账户后不会继续同步；停用前已缓存的邮件仍可阅读。
  • 多账户时可以指定一个主账户（设置 → 账户 → 选中账户 →「设为主账户」）：一轮同步里它最先刷新，侧栏与账户列表也排在最前，其余账户自动作为副账户。第一个添加的账户默认就是主账户。

同步策略

启动时自动增量同步打开客户端后自动检查新邮件；可在设置 → 通用关闭。
即时推送（IDLE）收件箱保持一条长连接，服务器一有新邮件立刻收下来（多数邮箱 1–3 秒）；服务器不支持推送时自动退回定时检查。
同步间隔定时检查的节拍（默认 1 分钟，可在设置 → 通用调整）：收件箱每拍都查，其余文件夹轮流扫，不会因为文件夹多而把间隔拖长。
正文下载可选择只保留邮件头、最近 7 / 30 / 90 天正文等档位；正文在阅读时按需下载。
手动刷新工具栏刷新按钮或 Ctrl+R / F5，会把所有文件夹完整刷一遍。
只同步一个账户多账户时不必等整轮刷新：点账户行右侧的刷新图标，或右键账户选「立即同步此账户」，只收这个账户的邮件，状态栏会显示该账户的进度与结果。
后台收到新邮件列表与侧栏未读数会自动刷新，不用手动刷新或切换文件夹。

本地优先与待同步

标记已读、星标、移动、删除、打标签等操作会先在本机生效，再异步回写服务器。网络中断时，状态栏会显示「待同步 N 项」，恢复后自动重试；仍失败的操作会留在待同步队列，重启后继续尝试。

文件夹

  • 左侧「文件夹」区域右键可新建、重命名、删除自定义文件夹；只有空文件夹允许删除。
  • 把邮件拖到文件夹，或用右键「移动到文件夹…」。移动本地立即生效：行会马上从当前列表消失，服务器回写在后台进行（状态栏先显示「正在后台同步服务器…」，完成后变成「已移动 N 封到「X」」）；这期间可以继续看信、搜信、切文件夹，不用等。
  • 多选之后直接按住其中任意一封拖到文件夹，就会整批一次提交（只建一条连接、一条服务器指令，几十封也很快），不需要在拖动过程中一直按着 Ctrl / Shift；只是单击（没有拖动）时仍会像平常一样把选区收成这一封。
  • 垃圾箱保留天数在设置 → 通用中调整；只有垃圾箱里的邮件才能永久删除，详见第 6 章。

邮件备注

左栏

  • 快捷视图：统一收件箱、未读、星标、含附件、草稿箱。它们跨文件夹聚合，不改变服务器目录。
  • 等待回复：查看标记为「等待回复」的邮件和到点提醒，入口在货代功能开启时显示。
  • 标签：点击标签跨文件夹查看同一业务状态的邮件；可以为标签录制快捷键。
  • 时效节点 / 业务单号：货代功能开启后显示；点击节点或单号进入一票货视图。
  • 文件夹：每个账户下的真实 IMAP 文件夹；右键新建、重命名、删除。

中栏

  • 工具栏提供写邮件、星标、删除、全部已读、筛选、会话模式、刷新与上下文侧栏开关。
  • 点「刷新」后按钮上的箭头会变成转圈的加载弧（悬停提示也会变成「正在同步…」），同步结束自动恢复并刷新列表。
  • 右侧的「上下文侧边栏」用一个分栏图标表示：面板打开时图标是主色、按钮带主色浅底，关闭时变灰，悬停提示直接写「已打开（点击隐藏）/ 已关闭（点击显示）」。
  • 搜索框在工具栏中段（不再占用标题栏），支持普通关键词与结构化运算符；右侧箭头展开高级筛选条。
  • 邮件行显示发件人、主题、摘要、时间、星标、附件、行业类型和业务单号徽标。
  • 多选邮件后，底部整行切换为批量处置条：已读、星标、归档、删除、取消。

右栏

  • 邮件头先显示，正文随后加载；正文下载中会显示「正在下载正文…」而不是空白。
  • 标题下方可回复、回复全部、转发、切换已读、星标、删除、打印。已读邮件的切换按钮显示「信封 + 未读点」表示点了会标为未读，未读邮件则显示对勾（标为已读）。
  • 右侧上下文侧栏显示同一发件人的往来邮件与附件；可用工具栏按钮隐藏。
  • 邮件头里的收件人 / 抄送 / 密送都是一样的地址单元：鼠标悬停高亮，左键弹出联系人卡片（写邮件 / 相关邮件 / 复制地址），右键还有「在通讯录中查看」。
  • 邮件备注仅保存在本机，不会发送给收件人。

04 · 阅读邮件

#

单击邮件在右栏预览，双击在独立阅读窗口打开；阅读窗口沿用主界面主题，可用 Esc 关闭。

独立阅读窗口默认按当前主窗体宽高的 85% 居中打开（小屏会自动限制在工作区内），也可以拖动边框调整大小；关闭后再双击会重新按主窗体尺寸打开。

阅读窗口里直接回信

独立阅读窗口顶部有「回复 / 回复全部 / 转发」三个按钮，效果和主窗口一致：引用原文、带上签名、进入写信窗口。草稿邮件仍然不能回复或转发（双击草稿是继续编辑）。

分段加载

打开邮件时先读取本地邮件头（主题、发件人、收件人、附件名、业务单号），正文与附件按需下载。即使正文很大或需要联网，邮件头与操作按钮也会先出现。

发件人与账户头像

  • 默认显示首字母色块（同一地址颜色固定），用来快速区分发件人。
  • IMAP 服务器没有取头像或通讯录的接口，所以客户端会在启动约 20 秒后、闲下来时按邮箱地址查一次 Gravatar：查到就把首字母换成真实头像，查不到保持原样。一个运行周期只尝试一次，最多查最近往来的 300 个地址。
  • 访问不到 Gravatar（国内网络经常超时）时会在连续几次失败后自动收手，不会反复重试、也不影响收发。
  • 开关在 设置 → 通用 → 「空闲时加载联系人头像（Gravatar）」，关闭后完全不发这类请求。查询会把邮箱地址的 MD5 发给 gravatar.com。

陌生发件人（首次来信）

  • 收信时客户端会判断这个发件人是不是「第一次来信」：通讯录里没有该地址、本地也从没收到过他的邮件，这封就会在列表发件人后面打一个琥珀色「陌生」小角标，阅读区顶部同时出现一条警告说明。
  • 反过来，发件人域名就是你们公司自己的企业域名时（同事用新邮箱第一次来信）不算陌生——域名已经说明是自己人了；公共邮箱（qq.com、163.com 等）不适用这条豁免。
  • 判定只在收信那一刻做一次：同一个人一次发来几封会一起标；下一轮再收到他的邮件就不再标了。已经收到的历史邮件不会追溯补标。
  • 提醒你在意的是「改收款账号 / 付款指令 / 换代理」这类邮件：主题抄得再像，地址是新的就值得核实一遍。
  • 确认对方没问题时，点阅读区提示条右侧的「加入通讯录」，以后他的来信就不会再被标为陌生（当前这封的标识保留，作为历史记录）。
  • 不需要这个提醒可以在 设置 → 通用 →「标记陌生发件人」关闭；关闭只是不显示，判定结果仍留在本地库里，重新打开立刻恢复。

退信（投递失败退回）

  • 你发出去的邮件被对方服务器退回时，客户端会在列表里给这封回信打一个红色描边的「退信」角标，排在「陌生」之前；阅读区（含独立阅读窗口）顶部出现红色提示条「投递失败 · 这封是退信」。
  • 判定看三样东西：邮件的 MIME 结构里有没有 message/delivery-status 段（标准退信报告）、发件人是不是 mailer-daemon / postmaster 这类退信系统、主题是否命中「退信 / 无法投递 / Undelivered」等关键词。结构命中就直接认定；结构拿不到时才要求「发件人 + 主题」同时成立，所以客户自己写的「关于退信的处理」不会被误标。
  • 只有「延迟投递提醒」（delivery delayed / 延迟）不算退信——那封邮件还在队列里重试，晚点可能送到。
  • 提示条第二行会写清失败收件人、SMTP 状态码与诊断（例如 收件人 ops@forwarder.cn · 5.1.1 550 User unknown）。这些细节来自退信里的 delivery-status 段，正文下载完成后才解析出来；还没解析到时提示条会写「展开正文查看失败原因」。
  • 新来信在收信那一刻判定；升级到带这个功能的版本时，会把本地已经收到的历史退信补标一次（只跑一次，普通来信不受影响）。不需要这个提示可以在 设置 → 通用 → 「标记退信邮件」关闭（关闭只是不显示，判定结果仍留在本地库，重新打开立刻恢复）。

仿冒域名警示（疑似钓鱼）

  • 钓鱼邮件最常用的手法是造一个和你自己公司域名几乎一样的域：把字母 l 换成 1、多写一个字母、换个后缀（.cn / .net），或者把你的域名夹在中间（你的域名.别人的域）。这类邮件的主题和正文能抄得一模一样，只有域名不对。
  • 客户端会拿发件人域名和你本机账户的企业域名比：形近、混淆字符、只换后缀、被夹在对方域名里——命中任一条就在列表显示红色「疑似钓鱼」角标，阅读区（含独立阅读窗口）顶部出现红色警示条，写明它像哪个域名、因为哪一条规则。
  • 红色警示比「陌生」的琥珀色更强，两者可以同时出现：既是从没来过信、域名又像你们公司，是最高风险的一类邮件。核实身份之前，不要按邮件里的账号付款或变更收款信息。
  • 公共邮箱域名不参与比较（qq.com、163.com、gmail.com、outlook.com 等）：这些域几十万人共用，拿来做相似度比只会误报，所以如果你只挂公共邮箱，就不会出现这类提示。
  • 开关与容差在 设置 → 通用 → 「检测仿冒域名（钓鱼警示）」：默认「差 1 个字符」，可放宽到「差 2 个字符」，放宽更容易命中、也更容易误报。判定是即时计算的，改完设置回到列表立刻生效，历史邮件同样适用，不需要重新收信。

正文与远程图片

  • 默认阻止远程图片，避免追踪像素；邮件中有远程图片时，正文上方会出现「显示图片」按钮。
  • 正文由 WebView2 渲染，支持 HTML 邮件、内嵌图片、表格与长引用；多层引用的长线程默认保留最近 5 层直接显示，更早的收成「显示更早的历史邮件（N 层）」，点一下展开。
  • 折叠的层数可以调：设置 → 通用里选「保留最近 5 / 6 … 10 层」；也可以整体关掉「默认折叠超长邮件的历史引用」，让长邮件直接铺开（缩进仍然会压平，不会越缩越窄）。
  • 历史引用里的图片如果没跟着这封邮件一起传过来（常见于对方客户端只保留引用、不带图片），正文会在原位置留一个「图」字小方块（鼠标悬停有说明），不会出现一排破图、也不会把签名栏撑乱。
  • 正文里的图片可以鼠标左键双击放大查看，也可以右键选「查看大图」：弹出独立窗口，滚轮缩放、按住左键拖动平视、双击在「适应窗口 / 实际大小」之间切换，Esc 关闭；窗口右下角能把这张图另存为文件。鼠标移到图片上会变成放大镜，表示可以双击。
  • 正文右上角的阅读工具栏可复制、打印；阅读字号跟随设置里的「字号」档位。
  • 少数邮件可能只同步到了邮件头、正文是空的（上次下载被打断、解析失败或正文缓存被清）。这时正文区中间会出现「重新获取正文」按钮，点一下会再向服务器拉一次这封邮件的正文，成功后原地显示，不用重新同步整个文件夹。草稿不会出现这个按钮（草稿正文是本地内容）。

AI 总结（本机小模型）

  • 阅读工具栏与独立阅读窗口的操作条都有「AI 总结」按钮：点一下才出现摘要卡片（阅读区平时不占位置），把正文压成要点 / 待处理 / 单号三段，几秒内看清这封邮件要做什么。
  • 本地 AI 默认关闭：不开「启用本地 AI」时不加载模型、不下载、不占内存，「AI 总结」用规则抽取（关键词 / 单号 / 待处理事项，零依赖、秒出）。打开后改用本机小模型（Qwen2.5-0.5B，约 400 MB，按需下载），邮件正文不出本机、不联网；除下载模型外不发起任何网络请求，日志里也不记录正文。
  • 打开本地 AI 但模型还没下载、加载失败或推理超时，会自动退回规则抽取，卡片顶部会用琥珀色说明“已退回规则抽取”。
  • 摘要要求「不改数字、日期、单号」，没有提到的段落显示「未提及」；正文过长会先去引用、去签名，再按 3000 字一段切开逐段总结后合并（默认最多覆盖 6000 字），卡片会提示「已分 N 段总结」；再超出覆盖上限的部分会在卡片上说明，可在设置里调大。
  • 入口与参数都在 设置 →「本地 AI 助手」：启用本地 AI 开关、摘要引擎（自动 / 本地模型 / 规则抽取）、摘要长度、正文上限，以及模型的下载 / 删除 / 打开目录 / 重新检测。也可以把自己的 GGUF 文件放进模型目录后点「重新检测」。
  • 摘要只显示在卡片里、不写入数据库：换邮件或收起后就不占用空间，需要留档时点「复制摘要」；也可以直接在卡片里拖选某一条（或跨行一段）再 Ctrl+C，右键还有「复制 / 全选」。

查看邮件源码

  • 在邮件列表上右键 →「查看邮件源码」，或独立阅读窗口里右键邮件头（主题 / 发件人区域）→「查看邮件源码」，都能打开源码窗口。
  • 窗口会优先连服务器取原始 MIME（相当于在 webmail 里看「显示原文」），能看到真实的 Received、Reply-To、Authentication-Results 与原始 MIME 分段，用来核对发件人是否为伪造、排查乱码最有价值。
  • 断网、登录失败或服务器上已经没有这封邮件时，会退回本地重建版本（按客户端库里的字段重新拼一封），窗口顶部用琥珀色标明原因。两个版本都能另存为 .eml，Outlook / Foxmail 都能直接打开。
  • 工具条：复制全部（整份源码进剪贴板）、另存为 .eml（原始字节原样保存）、重新获取（再连一次服务器）。源码超长（> 4 MB）时窗口只显示前 4 MB 并提示，另存仍然是完整内容。
  • 查看源码是只读操作：不会把邮件标为已读、不改星标，也不写库。关闭窗口会自动取消还没取完的连接。

阅读收条

发件人请求阅读收条时，邮件头下方会显示提示；可以选择「发送回执」或「忽略」。忽略不会记录为已发送，下次打开仍会提示。

附件

  • 普通附件显示在正文下方；内嵌图片归入正文资源，不单独列出。
  • 双击附件用内置预览打开 PDF / 图片 / 文本（单击只选中，不会把文件弹出去）。
  • 右键菜单：下载附件（仅收取正文的账户）、预览、用本机程序打开、另存为、复制（等价于 Ctrl+C，把附件文件放进剪贴板，可直接粘到资源管理器、聊天窗口或新邮件里）、打开所在文件夹。
  • 附件预览窗口继承主界面的投影和标题栏，可调整大小。

阅读时顺手处理

打标签右键邮件 →「打标签…」，可多选标签；批量选中后同样适用。
标记待办右键 →「标记待办…」，填写标题与截止时间；到期会在托盘提醒。
等待回复右键 →「等待回复…」，到点只提醒一次；可在跟进窗口继续 +4 小时或手动催信。
添加到黑白名单右键发件人可直接加入黑名单或白名单，规则在本地生效。
作为附件转发右键 →「作为附件转发」（或阅读工具栏的回形针按钮）：把整封原邮件打包成 .eml 附件发出去，正文不带引用，适合原样转给同事或客户核对。
查看邮件源码右键 →「查看邮件源码」：看服务器原始 MIME（含真实收发路径与安全认证头），可复制、可另存 .eml；断网时显示本地重建版本并标明原因。
小技巧：按 Ctrl+A 全选当前页，再用底部批量条处理；按 / 可快速把焦点移到搜索框。
Write

05 · 写邮件

#

工具栏「写邮件」或 Ctrl+N 打开写信窗口。窗口支持最小化 / 最大化，默认按当前主窗体大小的 85% 打开并居中；小屏会自动限制在工作区内。

收件人与正文

  • 发件人下拉选择账户；收件人、抄送、密送支持从地址簿补全。点击「抄送 / 密送」展开对应行。
  • 主题独立一行；正文使用富文本编辑器，支持加粗、颜色、字号、列表、表格、图片与链接。
  • 右侧栏提供「快速文本 / 地址簿」：双击快速文本追加到光标处，双击联系人加入收件人。工具栏上的侧栏开关会记住上次的状态，下次写邮件自动沿用（第一次使用默认关闭）。
  • 右上角模板按钮可套用整封模板（含主题、正文、内容块与占位符）。

签名

每个账户一份签名。切换发件账户时，正文末尾的签名会实时替换；关闭该账户的「使用签名」后不再追加。签名由设置 → 签名维护。

  • 导出 / 导入：设置 → 签名下方有「导出…」「导入…」。导出生成一份 JSON（按邮箱地址记录每个账户的签名），换机器或给同事时导入即可；导入按邮箱地址匹配本地账户，命中的会覆盖该账户现有签名，本机没有的邮箱会列出来跳过。

附件与定时发送

  • 点附件按钮选择文件；附件仅保存路径，发送时再读取。编辑器里也能插入附件标识。
  • 点「发送」后邮件先进入发件箱，写邮件窗口立刻可以关闭，真正投递由后台线程完成——带大附件的邮件不用再等窗口。
  • 投递结果在主窗口底部状态栏与托盘气泡里提示；发送失败会保留在发件箱并自动重试，也可以在发件箱里手动「立即投递」。
  • 「定时发送」可填写 HH:mm，或用「延迟 1 分钟 / 延迟 30 分钟 / 明早 9 点」快捷设置；到点由发件箱后台投递。
  • 定时发送的邮件在发件箱中可见，可立即投递、重试或删除。

草稿与自动保存

  • 写信内容每 30 秒自动保存到本机；关闭窗口时若有未保存内容，会询问保存、放弃或取消关闭。
  • 「保存草稿 / Ctrl+S」会把草稿同时写入本机恢复文件和草稿箱；草稿箱中的草稿双击可继续编辑。
  • 如果上次异常退出，下次打开写信窗口会提示恢复未发送草稿；附件被移动或删除时会标出缺失文件。
  • 草稿邮件不能直接回复或转发，避免把未发送内容带进新邮件。

发送前检查

点发送时会检查漏附件、空主题、收件人过多等常见问题；提示只提醒不强制阻断，确认后可以继续发送。这项检查可以在设置 → 通用 → 「发送前检查」里关掉，关掉后点发送直接进入发送流程。发送成功后草稿会自动清理。

回复与转发：在右栏邮件头使用「回复 / 回复全部 / 转发」。草稿邮件会禁用这三个操作；转发会保留原邮件正文与附件信息。
Find & clean

06 · 搜索与整理

#

搜索框支持普通关键词与结构化运算符，多个条件按「与」组合；识别不了的运算符会保留为普通文本，避免搜不到。

输入 @ 选择语法

不用背运算符：在搜索框输入半角 @ 或全角 ＠，会弹出类似微信 @ 好友的语法菜单。继续输入可以过滤，例如 @附件 只剩「附件名 / 含附件」两项。

  • 菜单共 22 条，按「收件人 / 内容 / 状态 / 时间 / 货代单号 / 邮件类型」分组，每项都带中文说明和示例。
  • 方向键或 PageUp / PageDown 移动，Enter 或 Tab 插入；鼠标悬停选中、单击插入。
  • 插入 from:、booking: 等需要填值的语法时光标停在冒号后；has:attachment、is:unread 等完整语法会自动补空格。
  • Esc 只收起菜单、保留已输入的搜索词；再按一次 Esc 才清空搜索。
  • 触发符必须在开头或空白之后；邮箱地址里的 @ 不会误弹菜单。
组合使用：先输入普通关键词，再输入 @ 选择运算符，例如 放舱 @from: 后继续输入发件人。多个条件之间仍是「与」关系。

常用搜索语法

写法作用
booking:SO123按订舱号 / SO 搜索业务单号
bl:HBL123 / ctr:ABCD1234567按提单号 / 箱号搜索
ref:ABC任意类型的业务单号
from:ops@example.com按发件人
subject:"放舱通知"按主题（含空格时加引号）
filename:SI按附件名
has:attachment只看含附件邮件
is:unread / is:starred未读 / 星标
type:si按行业邮件类型
after:7d / before:2026-10-01时间范围

搜索结果与文件夹列表分开

在搜索框输入内容后按 Enter 才进入搜索结果；之后点击左侧文件夹会直接回到该文件夹的普通邮件列表，搜索框文字保留。想再看刚才的搜索结果，再按一次 Enter 即可，不需要重新输入。

  • 搜索结果顶部有「当前文件夹 / 所有邮件」两个范围：当前文件夹只查左侧选中的文件夹 / 快捷视图 / 标签，所有邮件跨账户、跨文件夹聚合。
  • 切换范围会重新查询并更新列表数量；「所有邮件」默认排除垃圾箱。
  • 只有搜索结果模式才显示搜索条件胶囊；点搜索框右侧 × 会同时清空条件并回到文件夹列表。

全部搜索条件（对齐 Foxmail）

搜索框右侧箭头展开「全部搜索条件」面板，条件与 Foxmail 的搜索面板一一对应：

  • 发件人 / 收件人 / 主题 / 全文四个文本框：收件人一栏同时查收件人、抄送与密送；全文查正文纯文本。
  • 附件可选「不限 / 有附件 / 无附件」，右侧再填附件名关键词；标签可选「不限 / 有标签 / 无标签 / 某个标签」；提醒可选「不限 / 有提醒 / 无提醒」（提醒指进行中的等待回复或未完成待办）；备注在本地备注里查。
  • 时间：时间不限 / 今天 / 三天内 / 一周内 / 一个月内 / 一年内 / 自定义（选自定义后出现起止日期）。
  • 条件之间是「与」关系，可以和搜索框里的 booking:、自由关键词叠加；字段值可以直接从邮件正文复制粘贴；Enter 应用，Esc 收起，重置清空全部条件。
  • 面板右上角的 + 可以勾选要显示哪些条件（发件人 / 收件人 / 主题 / 全文 / 附件 / 标签 / 提醒 / 备注 / 时间），已勾选的条件前有 ✓；取消勾选的条件会从面板上收起，其余条件自动重排。选择会记进设置，下次启动保持。

多选与批量

  • Ctrl+单击或 Shift+单击多选；勾选后底部出现批量条。
  • 批量已读、星标、归档、删除只影响选中邮件；批量操作先本地生效，再异步回写服务器。
  • 取消批量选择后，底部恢复分页条。

垃圾箱与永久删除

永久删除不可撤销。

普通「删除」只是移动到垃圾箱；只有垃圾箱里的邮件才提供永久删除。永久删除会先尝试服务器 \Deleted + UID EXPUNGE，成功后再删除本地记录；操作前会二次确认。

Organize

07 · 标签、规则与模板

#

标签

  • 设置 → 标签：新建标签、选颜色、录制快捷键。标签是本地业务状态，不写入服务器。
  • 点击快捷键框后直接按组合键即可录制；按 Backspace / Delete 或点框内 ✕ 解绑。
  • 快捷键只在主窗口生效，输入文字时不会触发；重复组合键会被拒绝。
  • 邮件右键「打标签…」可多选；批量选中邮件后同样适用。

规则

  • 条件支持「发件人包含 / 发件域包含 / 主题包含」，多个条件为「与」关系。
  • 动作可叠加：星标、已读、打标签、移动到文件夹、归档、标记垃圾邮件；移动 / 归档 / 垃圾会终止后续规则。
  • 勾选「命中后继续执行后续规则」可让多条规则依次生效。
  • 规则默认只处理同步新入库的邮件；选中规则后点「对已有邮件执行一次」可补跑（Inbox 最近 500 封 / 全文件夹 2000 封）。

模板与快速文本

整封模板可保存主题、富文本正文、分组、内容块与占位符；写信时从模板按钮套用。
快速文本纯文本话术，原样追加到光标处，不覆盖已写内容；适合报价、催款、标准回复。

两者都在设置 → 模板维护，分为「邮件模板 / 快速文本」两个 Tab；支持导入 / 导出 JSON，便于同事之间共享。占位符如 {主题}、{日期}、{客户名称} 会在套用时替换。

签名

设置 → 签名按账户维护富文本签名，支持加粗、颜色、字号与图片。签名只在写信时追加，不会重复插入已有正文。

Freight workflow

08 · 货代工作流

#

设置 → 货代有总开关与四个子项：业务编号、行业邮件类型、时效节点、等待回复。不做货代业务时可以整体关闭，界面会回到通用邮箱形态。

业务编号

从主题与正文抽取 Job / SO / B/L / 箱号 / 封号 / 船名航次 / 港口 / 发票号 / PO / 空运单等标识。邮件头显示业务卡片，左栏按单号聚合，搜索支持 booking:、bl:、ctr: 等运算符。

行业邮件类型

按主题与正文关键词识别订舱确认、SI、VGM、提单草稿、AN、账单、查验、甩柜、延误等类型。邮件头显示类型标签，搜索可用 type:si 等关键字。

时效节点与一票货

  • 识别截关、截补料、VGM、单证、ETD、ETA 等节点，左栏按时倒计时；点击节点进入对应的一票货案件。
  • 案件页把同一票货的邮件、附件与时间轴聚在一起，可导出资料包。
  • 邮件头「查看一票货」按钮也能进入案件；搜索业务单号可跨文件夹找回相关邮件。

等待回复

  • 右键邮件「等待回复…」设置跟进时间；到点只托盘提醒一次，避免反复打扰。
  • 在「等待回复」窗口可以继续跟进（+4 小时）或手动催信；客户端不会自动替用户发催信邮件。
关闭功能不会删数据。

关闭货代子项只影响之后入库的识别与界面入口；已识别的数据保留，重新开启后会自动补扫这段时间的邮件。

Reminders

09 · 待办、提醒与锁屏

#

待办

邮件右键「标记待办…」填写标题与截止时间。待办只保存在本机；到期未完成时托盘弹出提醒，已提醒的待办不会重复弹。完成的待办会归档，可在待办列表查看逾期状态。

托盘与全局热键

  • 默认关闭主窗口时最小化到托盘，后台同步、定时发送与提醒继续运行；可在设置 → 通用改为直接退出。
  • 托盘右键菜单可以显示主窗口、检查新邮件、退出。
  • 设置 → 通用 → 全局热键可注册系统级组合键：主界面在前台时隐藏到托盘，否则从任意程序切回主界面。
  • 设置 → 通用 → 诊断与日志：运行日志写在数据目录的 logs 下，按天一个文件，最多保留最近 7 天（可选 1 / 3 / 5 / 7 天），超期的在程序运行期间自动删除；那里也能看到当前占用，并手动清理一次。

客户端锁屏

  • 设置 → 通用 → 安全：设置锁定密码后可启用客户端锁定；锁定状态下必须输入密码才能查看邮件。
  • 可设置空闲多久自动锁定；解锁密码框获得焦点时，窗口级快捷键会被屏蔽。
  • 锁定只保护界面访问，不改变本机数据库文件；共用电脑时仍建议使用 Windows 账户隔离。
Data

10 · 数据与备份

#

数据在哪里

设置 → 数据 / 存储与清理可以看到当前数据目录。默认在 %APPDATA%\ZungMail：数据库 mail.db、原始邮件 eml\、运行日志 logs\、设置与模板 settings.json / templates.json、头像缓存 avatars\ 都在这个目录里，目录位置记在 location.json 中。另外 %LOCALAPPDATA%\ZungMail 只放可以丢弃的缓存（WebView2\ 渲染缓存与升级下载的 updates\），删掉会自动重建，不影响邮件。全部邮件保存在本机 SQLite（WAL + FTS5 全文索引），不依赖云端。

自定义数据目录

设置 → 数据可选择新的数据保存目录。选择后不会立刻复制，而是写入指针，下次启动时迁移；旧目录会保留作备份。迁移执行前，客户端仍照常使用旧目录（日志也写在旧目录），不会提前往新目录里写文件。不要选择网络盘或同步盘，避免数据库锁与损坏。

如果目标目录里只剩上次失败留下的 logs、avatars 等程序自建产物，预检会通过并在迁移前自动清掉它们，不会因此提示「不是空目录」；只有放着自己的文件（比如照片、其它程序的数据）时才会被拒绝。想重试：重新选择同一个目录即可。

从旧版 MailClient 升级：数据自动接管

1.2.0 起软件改名为 ZungMail，数据目录也随之从 %APPDATA%\MailClient 换成 %APPDATA%\ZungMail。第一次启动 ZungMail 时会自动接管旧数据，不需要手工搬文件夹：

  • 旧数据在默认位置 %APPDATA%\MailClient：直接把整个目录改名成 %APPDATA%\ZungMail。同一个盘符下改名是秒级的，不复制文件、不额外占空间。
  • 旧数据放在自定义目录（以前在设置 → 数据里改过位置）：只把 location.json 指针改成原目录，文件原地不动。
  • 接管失败时（旧目录被占用、权限不足）客户端不再搬动文件，而是把数据目录直接指到旧的 %APPDATA%\MailClient「原地接管」，邮箱照常打开、数据一条不少。想把它挪到新路径：彻底退出 ZungMail（含托盘）后删掉 %APPDATA%\ZungMail 里只剩指针的文件，再把 %APPDATA%\MailClient 改名成 %APPDATA%\ZungMail，然后重新启动。
接管过程不删除用户邮件。

它只改目录名或指针，账户、邮件、标签、规则、模板与签名都原样带过来。想确认是否接管成功：设置 → 数据里显示的数据目录应当是 %APPDATA%\ZungMail，并且账户数、邮件数与升级前一致。

导入与导出

导入 .eml把 Foxmail / Outlook 导出的 .eml 批量导入指定账户与文件夹，按 Message-ID 去重。
导出 ZIP把数据库与 .eml 原始邮件目录打包，便于本机备份或迁移。
联系人支持 vCard（.vcf）与 CSV 导入导出；通讯录列表按每页 50 位分页，顶部搜索框可按姓名或邮箱即时过滤（Esc 清空）。
缓存清理清理正文缓存只删正文与附件缓存，邮件头保留；阅读时重新下载。重建搜索索引用于修复搜索不到邮件。
历史邮件清理按账户 / 文件夹 / 时间 / 大小 / 附件类型筛选后「预览匹配」，列表按 50 封分页，可全选本页 / 反选本页 / 全选 / 反选后再「清理选中」；整封删除会进隔离区可撤销，勾「仅清理正文和附件」则只清缓存、不删邮件（该模式不可撤销）。

卸载与数据保留

卸载程序都会先删除安装目录（默认 C:\Program Files\ZungMail），数据目录默认不动：MSI 安装包只移除程序文件与快捷方式；NSIS 安装包（setup.exe）还会多问一次是否同时删除 %APPDATA%\ZungMail 与 %LOCALAPPDATA%\ZungMail，选「否」就保留邮件、账户、标签、规则与模板，重新安装后继续使用。

这些操作不可撤销：永久删除垃圾箱邮件、历史清理里勾选「仅清理正文和附件」、清理正文缓存、重建索引、卸载时选择删除数据。执行前确认已经备份需要的邮件与附件。
Settings & update

11 · 设置与升级

#

常用设置

  • 外观：默认 / 淡蓝 / 淡粉 / 淡橙四套浅色主题，选中即时预览，点「保存设置」长期生效。
  • 字号：紧凑 / 标准 / 较大，同时影响列表与正文阅读字号。
  • 分页大小：列表始终分页加载，可调整每页封数。
  • 正文下载：控制历史邮件正文与附件的下载范围，节省磁盘与流量。
  • 客户端锁定：设置密码与空闲自动锁定时间。

在线升级

  1. 设置 → 升级填写升级服务根地址（域名、IP 或完整 URL，可带端口与路径前缀）。
  2. 可设置启动后自动检测的延迟；也可以随时点「立即检测」。
  3. 发现新版本时状态栏出现版本标识，打开升级窗口可查看更新说明、大小与发布时间。
  4. 点「下载」后显示进度并允许取消；下载完成会校验 SHA256 与文件大小，再进入「待安装」。
  5. 「立即安装」会先保存设置与草稿，再启动安装程序并退出客户端；装好后客户端会自动重新打开，覆盖安装不会删除数据目录。
  6. 如果这一版发布的是便携版 zip，升级窗口不会出现「立即安装」：按钮是「下载并打开文件夹」，下载完解压覆盖程序目录即可（覆盖前先退出客户端，写 Program Files 需要管理员权限）。
  7. 从旧版 MailClient（1.1.x）升级到 ZungMail 1.2.0 是原地升级：安装包沿用同一个升级标识，不需要先卸载旧版。装完旧程序文件被移除，安装目录变成 C:\Program Files\ZungMail；数据目录由客户端在下次启动时自动接管（见第 10 章），邮件与设置都不动。
没有配置升级服务？

客户端不会发起网络请求，状态显示「未配置升级服务」。这不影响收发邮件；需要使用在线升级时再填写地址。

Troubleshooting

13 · 常见问题

#
QQ 邮箱提示登录失败，怎么办？
QQ 邮箱不能直接用网页登录密码。请在 QQ 邮箱网页版「设置 → 账户」开启 IMAP/SMTP 服务并生成授权码，把授权码填到客户端的密码框。若之前关闭过服务，重新开启后可能需要等待几分钟生效。
一直显示「正在同步」或收不到新邮件？
先看状态栏的同步进度与错误提示。检查网络、IMAP 服务是否开启、授权码是否过期；企业邮箱可能需要管理员允许 IMAP 登录。确认后点刷新按钮重试，客户端会复用正在进行的同步，不会重复建连接。
正文是空白的 / 图片不显示？
正文按需下载，先等状态栏或正文区的「正在下载正文…」结束。远程图片默认被阻止，点正文上方的「显示图片」放行。若仍为空白，检查 WebView2 运行时是否安装，或在设置里尝试关闭 HTML 渲染后重新打开邮件。
搜索不到明明存在的邮件？
先确认搜索的是本地已同步的文件夹；历史邮件可能只保留了邮件头，需要先同步。记不住运算符时，在搜索框输入 @ 从菜单里选，比手打更不容易拼错；也可以改用高级筛选条。搜索索引异常时，到设置 → 数据点「重建搜索索引」。
标签快捷键为什么没有反应？
标签快捷键只在主窗口、且焦点不在输入框 / 正文编辑器时生效。检查快捷键是否与其它标签重复；录制后需要点「保存标签」。如果组合键被其它程序占用，换一个组合键即可。
升级服务检测失败怎么办？
先确认设置 → 升级里的地址能访问，且服务端已发布高于当前版本的安装包。错误提示会区分未配置、地址不合法、无法连接和校验失败；校验失败时安装包会被删除，重新下载即可。
从旧版 MailClient 升级过来，邮件和设置还在吗？怎么确认？
默认都在，升级不删数据。第一次启动 ZungMail 会把旧数据目录自动接管到 %APPDATA%\ZungMail（以前改过自定义目录的只改指针、文件原地不动）；接管遇到占用或权限问题时，客户端原地继续用旧目录，保证能打开邮箱，不会丢邮件。确认方法：设置 → 数据里的数据目录应当是 %APPDATA%\ZungMail，账户数、邮件总数、标签与规则数量与升级前一致；标题栏显示 ZungMail v1.2.0 说明装的是新版。详见第 10 章「从旧版 MailClient 升级：数据自动接管」。
AI 总结显示「规则抽取」，或模型下载很慢怎么办？
「规则抽取」说明这次没用上本地小模型：最常见是没打开「启用本地 AI」（默认关闭，去 设置 → 本地 AI 助手 勾上），其次是模型还没下载（点「下载模型」，约 400 MB），或者加载/推理失败（卡片上会写原因，可点「重新检测」或重新下载）。规则抽取不联网、秒出结果，先看清要点够用；想要更通顺的摘要再把模型装好。国内网络下模型下载慢时，可以把模型地址换成自己的镜像，或把已有的 GGUF 文件放进模型目录后点「重新检测」。
怎么看一封邮件的原始源码？
在邮件列表上右键 →「查看邮件源码」（独立阅读窗口里右键邮件头也可以）。窗口优先连服务器取原始 MIME，能看到 Received、Authentication-Results 等真实头部；断网或服务器上已没有这封邮件时，会退回本地重建版本，顶部用琥珀色说明原因。需要留档时点「另存为 .eml」，保存的是原始字节，Outlook / Foxmail 都能直接打开。查看源码不会把邮件标为已读。
重装 / 升级会丢邮件吗？
覆盖安装与在线升级不会删除数据目录。卸载时 MSI 只删程序文件与快捷方式；NSIS setup.exe 会问是否删除 %APPDATA%\ZungMail 与 %LOCALAPPDATA%\ZungMail，选保留后重新安装可继续使用。重要邮件建议先在设置 → 数据导出 ZIP 备份。
安装时提示「警告 1909：无法创建快捷方式 ZungMail.lnk」或装完找不到 ZungMail.exe 怎么办？
这类提示大多是同一个原因：电脑上的 360 安全卫士 / 360 天擎、火绒、腾讯电脑管家等把刚解压出来的 ZungMail.exe 当成可疑程序隔离（删除）了。主程序没了，安装器建快捷方式时自然指向不到文件，于是弹出 1909。
按这个顺序处理：
  1. 打开安全软件的「隔离区 / 恢复区」，把 ZungMail.exe 恢复，并加入信任区；360 安全卫士是「木马查杀 → 恢复区 → 恢复并信任」，再把整个安装目录（默认 C:\Program Files\ZungMail）加进「信任区」。
  2. 企业里装了 360 天擎 / 火绒企业版的，让管理员把 ZungMail 加进「软件白名单 / 信任目录」后重新下发。
  3. 加白之后重新运行一次安装包（覆盖安装即可，不需要先卸载）。
  4. 如果安装包本身被拦（双击就消失），同样把安装包加入信任后再运行；或改用 ZungMail-<版本>-x64.msi。
临时应急：程序已经装好但没有桌面图标时，打开 ZungMail → 设置 → 关于 → 「创建桌面快捷方式」即可补一个（不需要重装）；主程序被删掉时这个按钮也救不了，必须先加白再重装。
另一类少见情况是「公共桌面」C:\Users\Public\Desktop 被清理工具删掉导致快捷方式建不出来，重建该目录或按上面的按钮补图标即可。
