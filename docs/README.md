## 约定

1. **过程材料不进仓库**：需求调研、竞品/标杆分析、技术评估、PRD 与 UI 原型、分批落地记录、`openspec/changes/**` 都放在 `workdocs/`（已加入 `.gitignore`）。需要沉淀的结论写进上面的长期文档，而不是原样提交原始记录。
2. **只写结论与规则**：长期文档描述"现在是什么、为什么这样定、怎么验收"，不写开发流水账。
3. **不写对标产品**：文档只描述本产品自身的规则与取舍，不点名任何第三方产品；功能兼容性（例如"可导入第三方客户端导出的 .eml"）按功能事实描述。
4. **规格优先**：可验收的行为改动用 `openspec/specs` 记录；一次性方案讨论留在 `workdocs/`。
