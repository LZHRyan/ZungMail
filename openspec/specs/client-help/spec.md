# client-help Specification

## Purpose
让用户在没有网络、没有开发文档的情况下，也能从客户端设置直接打开一份完整的离线使用教程，按步骤完成账户配置、日常收发和货代工作流。

## Requirements

### Requirement: 设置内使用教程入口

客户端 SHALL 在「设置 → 关于」提供「使用教程」入口；用户点击后 SHALL 用系统默认浏览器打开程序目录中随包发布的 HTML 教程，不得依赖网络。

#### Scenario: 正常打开教程

- **WHEN** 用户在设置 → 关于点击「打开使用教程」
- **THEN** 系统默认浏览器打开安装目录 `Assets/help/user-guide.html`，显示中文教程首页，状态栏提示「已打开使用教程」

#### Scenario: 教程文件缺失

- **WHEN** 程序目录中的教程文件被删除或不可读，用户仍点击「打开使用教程」
- **THEN** 设置页显示包含缺失路径的提示，不弹出系统错误框，也不影响其它设置操作

#### Scenario: 从任意设置分区进入

- **WHEN** 用户当前停留在「账户」或「升级」等其它分区
- **THEN** 侧栏的「关于」仍可切换到教程入口，入口不依赖当前账户或升级服务配置

### Requirement: 教程随程序离线发布

教程 SHALL 是一个自包含 HTML 文件，CSS、脚本与图示全部内联，MUST NOT 引用外部网络资源；build、publish 与安装包 SHALL 包含该文件。

#### Scenario: 无网络安装后可读

- **WHEN** 用户在一台不能访问互联网的电脑上完成安装并打开教程
- **THEN** 页面样式、目录、步骤与常见问题均可正常显示，没有失败的字体、图片或脚本请求

#### Scenario: 发布产物包含教程

- **WHEN** 执行 Release 构建、publish 或制作 NSIS 安装包
- **THEN** 输出目录中存在 `Assets/help/user-guide.html`，安装后的程序目录中同样存在该文件

#### Scenario: 教程内容可定位

- **WHEN** 用户打开教程并浏览左侧目录
- **THEN** 能直接找到「快速开始 / 账户与同步 / 主界面 / 阅读邮件 / 写邮件 / 搜索与整理 / 标签与规则 / 货代工作流 / 数据备份 / 设置与升级 / 快捷键 / 常见问题」章节

### Requirement: 教程覆盖首次使用与核心工作流

教程 SHALL 以可执行步骤说明首次启动、添加账户、同步与阅读、写邮件、搜索整理、货代工作流和数据安全，并标注需要用户确认的高风险操作（如永久删除、覆盖安装）。

#### Scenario: 新用户按教程完成配置

- **WHEN** 用户第一次使用 ZungMail 并阅读「快速开始」
- **THEN** 能按步骤填写邮箱地址与授权码、测试连接并以「统一收件箱」开始阅读邮件

#### Scenario: 查找具体功能

- **WHEN** 用户需要写邮件、建规则、录制标签快捷键或配置升级服务
- **THEN** 教程对应章节给出入口位置、操作步骤与结果说明，而不是只有概念介绍
